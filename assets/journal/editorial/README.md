# Sovtiva Editorial Media System — 2026-11-13

Original first-party editorial artwork for the Journal and Research Desk.

- Artwork must clarify what the story is about. Cover graphics are not evidence of a claim.
- Conceptual UI is illustrative, not a screenshot of a functioning product or a proven integration.
- Do not treat generated financial tiers, data points, brand icons or charts as verified source data. For business-economics articles, the in-article chart must be based on the cited figures, and visual-only artwork is preferred.
- Visual articles should pair a single headline cover with one or more meaningful in-body diagrams (workflow, decision, sequence, relationship, comparison or technical architecture).
- Alt text describes the diagram's subject, not a duplicate of the headline.
- Use .jpg for the first generated image covers at 1200px long edge, and original .svg for scalable explanatory diagrams. Keep original source files and attribution in GitHub history.
- Current work is limited to SOVTIVA Journal and Research pages. No changes to lead-generation, checkout or partner operations.

Release QA: check both EN/ES, mobile fit, missing image URLs, caption factual accuracy, image size, and reading flow.
