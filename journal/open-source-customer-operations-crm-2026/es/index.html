Tres sistemas.
El mismo cliente.

Un inbox guarda conversaciones. Un CRM organiza relaciones. Un dashboard enseña qué atender. Confundirlos hace que los datos se dupliquen.

Un cliente escribe por WhatsApp, luego responde un correo y finalmente acepta una propuesta. Si nadie sabe quién lleva la conversación o qué sigue, instalar tres programas nuevos puede complicarlo todavía más.

Chatwoot, Twenty y Appsmith se parecen desde lejos. En realidad hacen trabajos diferentes: administrar mensajes, estructurar una relación comercial y mostrar operaciones.

Chatwoot: una bandeja compartida

Chatwoot reúne conversaciones de chat web, correo y varias integraciones con plataformas de mensajería. Incluye asignaciones, notas privadas, etiquetas e historial. Su mejor caso de uso aparece cuando dos personas atienden clientes desde aplicaciones distintas y no saben si alguien ya respondió.

Hay una advertencia importante: una integración anunciada con WhatsApp no significa que se pueda copiar sin esfuerzo el historial de una cuenta de WhatsApp Business. Hay que verificar la ruta oficial de Meta, permisos, propiedad del número, plantillas, costos por mensajes y el tratamiento de datos. Tampoco basta con que la plataforma permita mandar mensajes para que cualquier contacto no solicitado sea apropiado.

La base comunitaria de Chatwoot tiene licencia MIT; las funciones empresariales tienen otros términos. La prueba inicial debería ser un chat web de bajo riesgo, una asignación a Sofía, una nota interna y un cierre comprobable, sin importar de golpe todos los canales.

Twenty: un CRM que puede crecer con la empresa

Twenty ofrece objetos, campos y vistas que pueden configurarse como código. Una empresa que maneje servicios, comisiones por referidos y contratos de software puede necesitar etapas diferentes para cada oportunidad. Eso es más interesante que una lista genérica de contactos.

El riesgo principal es migrar demasiado pronto. Si Gmail y las hojas actuales ya contienen información útil, una transición implica reconciliar identidades, eliminar duplicados, definir propietarios, mantener permisos y comprobar que el historial no desaparezca. Un CRM más atractivo no resuelve etapas comerciales mal definidas.

Twenty utiliza principalmente AGPLv3, con partes empresariales y componentes MIT separados. Si algún día lo alojamos, modificamos o comercializamos, los términos concretos deben revisarse. Antes de adoptar la plataforma conviene probar con datos ficticios si permite registrar un dueño, estado, próximo paso, fecha y evidencia sin duplicaciones.

Appsmith: visualizar sin inventar otra base

Appsmith permite construir paneles internos conectados a bases de datos y APIs. Puede ser una buena solución para mostrar seguimientos vencidos, tareas bloqueadas, oportunidades por etapa y errores de sincronización. El repositorio indica licencia Apache-2.0 y métodos de instalación como Docker.

Una pantalla elegante puede ocultar cifras obsoletas. Un tablero confiable indica cuándo se consultó cada fuente y permite regresar al registro original. Si ya existe un buen informe en Google Sheets, un dashboard adicional tendría que demostrar una mejora clara en la toma de decisiones antes de justificar mantenimiento.

Por ejemplo, un consultorio podría necesitar que cada solicitud no clínica llegue a la persona correcta y tenga respuesta. No tendría sentido cargar datos médicos sensibles en un tablero comercial. En un negocio B2B el problema puede ser atribuir las referencias correctamente y evitar que dos vendedores escriban al mismo contacto. La herramienta depende del recorrido real del cliente.

El principio operativo

Arreglar primero la transferencia de información que hoy se pierde. Mapear desde el mensaje recibido hasta el trabajo entregado. Si el proceso puede ordenarse con una sola herramienta existente, no hace falta otra.

Aplicación para Sovtiva

Podemos investigar una bandeja compartida para solicitudes entrantes, pero necesitamos verificar las cuentas y las condiciones oficiales de cada red. El CRM queda como opción cuando el volumen comercial lo justifique; Appsmith, cuando haga falta consultar varias fuentes en un panel real. Ninguno de estos sistemas ha sido desplegado ni probado por Sovtiva a partir de esta investigación.

El servicio valioso para un cliente es reducir respuestas perdidas, trabajo duplicado y tiempo buscando contexto. Comprar software es un medio; dejar de perder oportunidades es el resultado a comprobar.
