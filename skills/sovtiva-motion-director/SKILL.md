# Sovtiva Motion Director / Internal working skill

This repository skill is a **tracked instruction file**, not an automatically installed or invoked ChatGPT plugin. Apply it in an agent with the codebase and renderer connected. No unauthorised purchases, model subscriptions, API usage or deployment.

## Operating sequence

1. Identify intended audience, one relevant pain, emotional hook and business utility; draft one original visual metaphor and a 15-second script before writing any animation code.
2. Choose ONE style, not a mixture: editorial paper cut, isometric systems, risograph, premium UI / data, kinetic type, evidence board, material-inspired motion. Store style palette and drawing/motion rules in a versioned asset.
3. Produce three still frames at 9:16: first frame (hook), turning point and payoff. Inspect on a narrow mobile viewport, contrast and 130px/100px safe margins. Do not proceed with bland text on generic backgrounds.
4. Storyboard the entire clip (at least 5 distinct visual states). Assign a transformation to each action. Statically zooming four PNG slides does NOT count as completed animation.
5. Use deterministic code and visual representations, never screenshots of product features not actually observed. Keep every output editable with source. Prefer HTML Canvas / GSAP / HyperFrames or Remotion if the licenses and runtime are verified. FFmpeg is a compiler/editor, not the storyboard.
6. Design transitions as cause/effect: lead moves -> state changes -> owner acts -> result. Use smooth easing and a camera move for narrative meaning.
7. Use original or explicitly licensed audio only, with separate approval if external spend. Video must be comprehensible without audio, but do not default to mute for every creative brief.
8. Produce H.264, 1080x1920, safe margins, captions, transparent project provenance. If requested, design 1:1, 4:5, and 16:9 as layouts, not blind crops.
9. Make a contact sheet at t=0.5, t=2, t=5, t=8, t=12 and near the end; verify visual variety, no overlap, movement coherence and correct text. Also run media metadata QA (ffprobe) and a representative playback check.
10. Require approval of the creative baseline, verify that the piece meets brief and legal constraints; only then distribute. Metricool schedule=PENDING, not publication success; verify actual provider state after release.

## Five vetoes

- Reject four static slide sequences unless the brief explicitly asks for a slideshow.
- Reject data, testimonials, product UI or numerical improvements that were not sourced or tested.
- Reject copied visual identities, performers or third-party copyrighted assets without rights.
- Reject text cutoffs, too-small labels, CTA occupying platform UI safe zones and missing source file.
- Reject 'quality verified' when only CI or file metadata passed. Actual frames must be inspected and, for final production, a human creative review.

## Proof ladder

P0 concept | P1 style frames | P2 storyboard | P3 generated MP4 | P4 visual/audio QA | P5 actual platform published state | P6 performance measured.
Never describe P3 as P5 or P6.

## Business prioritization

Use Sovtiva's brand look: deep navy, warm cream, soft aqua, muted burgundy and olive. Original one-of-one clothing creative must never be templatized into mass inventory. Show credible industry workflows, not fake client case studies. Operational policy: no Claude is required, no spend without CEO approval, privacy and rights preserved. Recommend an inexpensive reversible test before any plan upgrade.
